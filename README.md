# dimred_dash
Interactive scatter which reveal data processed by dimension reduction methods with ability to model features by clicking in the empty areas of ordination

Here I use some data which I used in another projects: 
- data about milk and alcohol products to imagine features of new products
- one processed [dataset from Pangea](https://doi.pangaea.de/10.1594/PANGAEA.870461)
- and my old own data from PhD project about Kara Sea benthos

Block with Javascript constructed with llm (I don't understand Javascript) with frames of task
In model part for restoration of features I used multi-output Random Forest and KNN with some preprocessing
